# stephenconklin.github.io

Source for **[stephenconklin.github.io](https://stephenconklin.github.io)**, the portfolio of Stephen Conklin:
remote sensing pipelines, web maps and dashboards, cartography, and GIS plugins.

Built with [Astro](https://astro.build) and deployed to GitHub Pages with GitHub Actions. Notes for working on the
site are in [`docs/README-dev.md`](docs/README-dev.md).
